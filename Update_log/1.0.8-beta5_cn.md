# Tuanzi's Mod 1.0.8-beta5 更新日志

---


## 漏洞修复与稳定性优化

- **修复灵笼贸易站在 `RestockTimer >= 8000` 后村民无法自动补货的问题**：
  - 根因：外部无业村民会通过原版 `YieldJobSite` 行为将相邻工作站 POI 移交为贸易站内无 AI 村民的 `POTENTIAL_JOB_SITE`，导致该工作站 POI 票被永久占用（`freeTickets = 0`），进而被补货检测中的 `Occupancy.HAS_SPACE` 过滤掉；同时未占用的相邻工作站也易被 48 格内自由村民抢占。
  - 修复：灵笼贸易站现改为**主动独占绑定**相邻 6 面中 1 个空闲的对应职业工作站为专属 `JOB_SITE`（不可多台共用、防止外部村民抢占），自动将存量存档中残留的相邻 `POTENTIAL_JOB_SITE` 无损自愈接管为专属工作站，在取出村民、玩家破坏释放、方块移除（`preRemoveSideEffects`）及 `/setblock replace` 替换（`setRemoved`）时安全归还工作站 POI 票，并通过 `YieldJobSiteMixin` 禁止外部村民向贸易站/无 AI 村民移交潜在工作站。

## 功能增强

- **蓝图桌方块替换支持彩色方块系列调色 GUI 与快捷改色**：
  - 在蓝图桌 3D 检视器的方块替换界面（`BlueprintBlockReplaceScreen`）中选择**彩色方块**（`tuanzis_mod:color_block`）、**彩色楼梯**（`tuanzis_mod:color_stairs`）或**彩色半砖**（`tuanzis_mod:color_slab`）并点击「确定」后，自动弹出与**油漆桶调色盘**完全一致的 RGB / Hex / 16 色预设调色 GUI，由玩家自由指定目标颜色后完成替换。
  - 当双击替换的原条目本身为彩色方块系列时，仅精确替换该对应颜色的格子（不影响同方块的其他颜色，双色彩色双半砖支持仅修改匹配一侧的颜色），并在替换界面额外提供**「修改颜色」**快捷按钮，一键弹出同款调色 GUI 直接改色。
- **蓝图桌 3D 预览与材料清单支持彩色方块按色细分**：
  - 为 `BlueprintPreviewLevel` 与 `BlueprintPreviewMesh` 接入 `BlockEntities` 染色数据读取，完整支持**彩色方块**（`tuanzis_mod:color_block`）、**彩色楼梯**（`tuanzis_mod:color_stairs`）与**彩色双半砖**（`tuanzis_mod:color_slab` 上下独立双色）在蓝图桌 3D 检视器中呈现真实自定义 RGB 颜色，同时优化大型彩色方块蓝图的网格烘焙性能。
  - 蓝图桌右侧材料清单与蓝图大炮「材料清单」成书现已按具体 RGB 色号（如 `彩色方块 #AA71C5`）独立展示彩色方块图标、色条、色值与数量占比，并在蓝图桌 3D 预览中支持**单击按具体颜色单独高亮过滤**。
- **蓝图大炮支持彩色方块精确按色消耗与油漆桶染色打印**：
  - 蓝图大炮打印彩色方块/楼梯/半砖时，优先消耗周围容器（含嵌套潜影盒/黄金口袋）中**对应颜色**的同类方块；
  - 若缺少对应颜色的彩色方块，将自动检查容器中是否存在可用耐久的**油漆桶**（`tuanzis_mod:paint_bucket`）与其他颜色的同类彩色方块，消耗 **1 点油漆桶耐久 + 1 个其他颜色同类方块** 染色后直接打印（油漆桶耐久耗尽时自动变为空铁桶，与合成配方规则完全一致）；若既无对应颜色也无可用油漆桶则正常缺料暂停。
- **优化结构蓝图物品悬浮提示中的实体列表显示**：
  - 当结构蓝图包含过多实体（超过 4 个）时，物品悬浮提示（Tooltip）默认仅展示前 **4** 行实体条目并显示剩余数量及 `按住 Shift 显示全部` 提示；按住 `Shift` 键后立即展开全部实体列表。
  - 同时为压缩存储格式（`CompressedPayload`）的蓝图增加实体摘要缓存解析，仅在首次悬停且 `EntityCount > 0` 时轻量解码一次，兼顾完整列表展示与悬停帧率性能。
- **创造核心免除压缩建造浆料消耗**：
  - 当蓝图大炮在周围容器内检测到**创造核心**（`tuanzis_mod:creative_core`）时，`hasFuel` 与 `consumeFuel` 将直接放行，不再消耗槽位内的**压缩建造浆料**与剩余燃料耐久（即使大炮燃料槽为空也可在生存模式下无限发射建造与拆除）。
- **优化拼豆图纸转蓝图工具对白色/浅色色号格的识别**：
  - 新增白色/近白色格子内部黑色色号文字检测（基于 HSV 明度通道 `max(R,G,B)` 与上下亮边夹中间暗谷的垂直对比度），能够可靠区分**需填充白色的色号格**与**无字空白背景/红线/相邻黑边渗色**；无论白色拼豆位于图案内部还是暴露在外轮廓边缘，均不再被误判为空气，而是准确填充对应的白色或浅色 `tuanzis_mod:color_block`。
  - 优化原色归并聚类逻辑，对保留的白色/近白色色号格独立归并，防止少量白色高光或米白色格在默认 ΔE 合并下被浅肤色等邻近浅色吞并。
- **新增压缩建造浆料、空白蓝图与蓝图桌有序合成配方**：
  - **压缩建造浆料**（产出 3 个）：第一行 `火药×3`，第二行 `火药 + 岩浆桶 + 火药`，第三行 `岩浆桶 + 火药 + 岩浆桶`（合成后自动返还 3 个空铁桶）。
  - **空白蓝图**（产出 1 个）：第一行 `纸×3`，第二行 `淡蓝色染料 + 纸 + 淡蓝色染料`，第三行中间 `木棍`。
  - **蓝图桌**（产出 1 个）：第一行 `刷子 + 空白蓝图 + 书与笔`，第二行与第三行左右两侧各放置 `任意木板`（中间留空）。
  - 同步更新对应物品/方块的 JEI 说明文本。
