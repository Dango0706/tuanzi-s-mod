# Tuanzi's Mod 1.0.8-beta4 更新日志

---

## 版本更新

- 模组版本号正式更新为 **1.0.8-beta4**。

## 漏洞修复与稳定性优化

- **修复专用服务端启动时 `PistonMovingBlockEntity` Mixin 注入失败崩溃**：
  - 修复部分服务端环境下因其他模组修改或覆写 `PistonMovingBlockEntity#tick` 导致无描述符目标选择器扫描失败（`Redirector tuanzis_mod$skipSideEffectsOnTickSetBlock ... Scanned 0 target(s). No refMap loaded.`），从而在 `Blocks.<clinit>` 阶段引发服务器无法启动的问题。
  - 经验证原版 `PistonMovingBlockEntity#tick` 与 `finalTick` 在放置落地状态前已移除旧方块实体，且 `BlockBreakerBlockEntity#preRemoveSideEffects`、`setLevel`、`serverTick` 兜底及 `PistonBaseBlockMixin` + `BlockBreakerPistonManager` 已完整覆盖普通/粘性活塞推拉、连推与 1-tick 短脉冲下的防掉落与防复制迁移逻辑；因此正式移除冗余的 `PistonMovingBlockEntityMixin` 注册（并将原源码归档为 `.bak`），彻底消除活塞移动方块实体的 Mixin 冲突风险。
- **修复大型彩色方块蓝图在打开蓝图桌/蓝图大炮时触发原版 2MB NBT 网络解码崩溃（`NbtAccounterException`）**：
  - 结构蓝图物品（`StructureBlueprintItem`）现采用 GZIP 压缩载荷（`CompressedPayload`）透明存储 `Palette`、`Blocks`、`BlockEntities` 与 `Entities`（13,824 格彩色方块蓝图由约 6.3 MB 降至 ~45 KB），外层保留尺寸、方块数与虚影姿态等轻量字段，彻底消除 `container_set_content` 超出原版 2,097,152 字节限制导致的断连崩溃。
  - `BlueprintTableBlockEntity` 与 `BlueprintCannonBlockEntity` 在加载存档、放入槽位与打开界面前自动无损压缩旧版未压缩结构蓝图，已有存档可直接正常打开无需重做蓝图。
  - 同步补全旧版未压缩结构蓝图在 `ItemStack` 存档反序列化（覆盖掉落物 `ItemEntity`、物品展示框 `ItemFrame`、展示实体 `ItemDisplay`、玩家背包与原版箱子/潜影盒等）、`ItemEntity#setItem`、`ItemFrame#setItem` 及 `StructureBlueprintItem#inventoryTick` 中的自动无损压缩，彻底修复旧存档内遗留未压缩蓝图实体同步时触发 `clientbound/minecraft:set_entity_data` 2MB NBT 解码断连崩溃（`NbtAccounterException`）的问题。

## 功能增强

- **蓝图桌 3D 预览与材料清单支持彩色方块按色细分**：
  - 为 `BlueprintPreviewLevel` 与 `BlueprintPreviewMesh` 接入 `BlockEntities` 染色数据读取，完整支持**彩色方块**（`tuanzis_mod:color_block`）、**彩色楼梯**（`tuanzis_mod:color_stairs`）与**彩色双半砖**（`tuanzis_mod:color_slab` 上下独立双色）在蓝图桌 3D 检视器中呈现真实自定义 RGB 颜色，同时优化大型彩色方块蓝图的网格烘焙性能。
  - 蓝图桌右侧材料清单与蓝图大炮「材料清单」成书现已按具体 RGB 色号（如 `彩色方块 #AA71C5`）独立展示彩色方块图标、色条、色值与数量占比，并在蓝图桌 3D 预览中支持**单击按具体颜色单独高亮过滤**。
- **蓝图大炮支持彩色方块精确按色消耗与油漆桶染色打印**：
  - 蓝图大炮打印彩色方块/楼梯/半砖时，优先消耗周围容器（含嵌套潜影盒/黄金口袋）中**对应颜色**的同类方块；
  - 若缺少对应颜色的彩色方块，将自动检查容器中是否存在可用耐久的**油漆桶**（`tuanzis_mod:paint_bucket`）与其他颜色的同类彩色方块，消耗 **1 点油漆桶耐久 + 1 个其他颜色同类方块** 染色后直接打印（油漆桶耐久耗尽时自动变为空铁桶，与合成配方规则完全一致）；若既无对应颜色也无可用油漆桶则正常缺料暂停。
- **优化结构蓝图物品悬浮提示中的实体列表显示**：
  - 当结构蓝图包含过多实体（超过 4 个）时，物品悬浮提示（Tooltip）默认仅展示前 **4** 行实体条目并显示剩余数量及 `按住 Shift 显示全部` 提示；按住 `Shift` 键后立即展开全部实体列表。
  - 同时为压缩存储格式（`CompressedPayload`）的蓝图增加实体摘要缓存解析，仅在首次悬停且 `EntityCount > 0` 时轻量解码一次，兼顾完整列表展示与悬停帧率性能。
- **创造核心免除压缩建造浆料消耗**：
  - 当蓝图大炮在周围容器内检测到**创造核心**（`tuanzis_mod:creative_core`）时，`hasFuel` 与 `consumeFuel` 将直接放行，不再消耗槽位内的**压缩建造浆料**与剩余燃料耐久（即使大炮燃料槽为空也可在生存模式下无限发射建造与拆除）。
- **优化拼豆图纸转蓝图工具对白色/浅色色号格的识别**：
  - 新增白色/近白色格子内部黑色色号文字检测（基于 HSV 明度通道 `max(R,G,B)` 与上下亮边夹中间暗谷的垂直对比度），能够可靠区分**需填充白色的色号格**与**无字空白背景/红线/相邻黑边渗色**；无论白色拼豆位于图案内部还是暴露在外轮廓边缘，均不再被误判为空气，而是准确填充对应的白色或浅色 `tuanzis_mod:color_block`。
  - 优化原色归并聚类逻辑，对保留的白色/近白色色号格独立归并，防止少量白色高光或米白色格在默认 ΔE 合并下被浅肤色等邻近浅色吞并。
