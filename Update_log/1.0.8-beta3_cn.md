# Tuanzi's Mod 1.0.8-beta3 更新日志

---

## 版本更新

- 模组版本号正式更新为 **1.0.8-beta3**。

## 物品与玩法优化

- **主世界建筑高度限制解除与热加载配置**：
  - 将主世界（`minecraft:overworld`）底层安全高度空间扩展至原版引擎极限（`Y = 2031`，即上界 `2032`），不影响原版主世界地形生成、下界或末地。
  - 在模组主配置文件 `config/tuanzis_mod/config.json` 中新增 `overworldMaxBuildHeight` 配置项（范围 **320 ~ 2032**，默认 **2032**；其中 `320` 对应原版最大可放置 `Y = 319`，`2032` 对应最大可放置 `Y = 2031`）。
  - 支持多途径无重启热加载并自动向在线客户端同步生效：
    1. **管理员指令**：`/tuanzis_mod config get overworldMaxBuildHeight`、`/tuanzis_mod config set overworldMaxBuildHeight <320..2032>` 及 `/tuanzis_mod config reload`。
    2. **ModMenu 配置界面**：新增数字输入框与「原版 320」/「最大 2032」快捷预设按钮，保存后单人世界立即热生效。
    3. **后台文件自动热加载**：内置基于 `WatchService` 的后台监听线程（`ModConfigWatcher`），外部直接修改 `config/tuanzis_mod/config.json` 保存后即可自动重载并同步至服务端与所有玩家。
- **不死药水堆叠上限提升**：将所有药水类型的不死药水（普通饮用型、喷溅型、滞留型，含普通版与延长版）的最大堆叠上限从 1 提升至 **16**。
- **幸运属性联动赌场胜率**：
  - 玩家的“幸运（`minecraft:luck`）”属性现已正式影响赌场全部单人及单局胜率机制（轮盘、赛鸭、老虎机、幸运转盘、弹珠台、21 点、德州扑克）。
  - 每 **1 点幸运** 提升 **+0.5%** 玩家胜率，每 **1 点霉运（负幸运值）** 减少 **0.5%** 玩家胜率。
- **领队僵尸击杀经验优化**：
  - 击杀带有领队加成（`minecraft:leader_zombie_bonus`）的“领队”僵尸（含僵尸、尸壳、溺尸、僵尸村民等）时，基础掉落经验调整为 **最大生命值 ÷ (2.5 ~ 4.5)**。
  - 若该领队僵尸为**幼年**形态，则掉落经验**翻倍**。

## 新增附魔：祥瑞 & 厄兆

- **祥瑞 (`auspicious`)**：
  - 头盔专属非宝藏附魔，稀有度为 **UNCOMMON**，最高等级 **IV 级**。
  - 佩戴时每级增加 **+0.5 点** 玩家幸运值（IV 级提供 **+2.0** 幸运值）。
  - 与「厄兆」互斥；可通过附魔台、战利品宝箱、图书管理员交易及创造模式物品栏获取，已注册 JEI 说明页。
- **厄兆 (`ill_omen`)**：
  - 头盔专属**诅咒性附魔**，稀有度为 **UNCOMMON**，最高等级 **IV 级**（名称显示为红色，砂轮不可祛除）。
  - 可在**附魔台**直接附魔获得（也可通过战利品宝箱、图书管理员交易及创造模式物品栏获取）。
  - 佩戴时每级减少 **0.5 点** 玩家幸运值（IV 级降低 **2.0** 幸运值），并与「祥瑞」互斥，已注册 JEI 说明页。

## 武器调整与增强

- **裂虚之痕 (`rift_scar`)**：新增自带 **0.25 横扫攻击比率**（`Attributes.SWEEPING_DAMAGE_RATIO` 主手属性加成），提升群体横扫输出能力，并可与“横扫之刃”附魔效果叠加（最高不超过原版上限 1.0）。

## 新增内容：净化药水与背水药水

- **净化药水 / 净化脉冲 (`purifying` / `long_purifying` -> `purifying_pulse`)**：
  - 含普通版（45 秒）、延长版（90 秒）及其喷溅型、滞留型与药箭变体（暂无合成配方，已加入创造模式物品栏与 JEI 说明）。
  - 饮用瞬间清除身上所有牛奶可清除的负面状态，完整保留正面与中性状态。
  - 持续期间每 5 秒自动清除 1 个当前可净化负面状态，且新获得的牛奶可清除的负面状态持续时间 **-50%**。
  - 对「肾上腺素透支」无效（不清除亦不缩短其持续时间），且不清除 Boss 过热条等非状态效果机制。
- **背水药水 / 背水一战 (`desperate_stand`)**：
  - 持续 30 秒，无延长版本（含喷溅型、滞留型与药箭变体，暂无合成配方，已加入创造模式物品栏与 JEI 说明）。
  - 效果期间近战伤害 **+10%**；受到的常规伤害不立即扣血，而是以**创伤值**形式延迟记账。
  - 延迟期间每击杀 1 个敌对生物，创伤值减少该生物**最大生命值 × 10%**。
  - 效果结束后的 1 tick 统一结算（提前清除仍会结算）；若剩余创伤值大于 0，将受到等额**真实伤害**（无视护甲、抗性、伤害吸收，可致死；不死图腾与不死药水仍可触发免死）。
  - 新增常驻**白色心形创伤条 HUD**：默认显示在生命条上方 2px，格式为 `创伤 37 | 18s`（整数不显示 `.0`，创伤为 0 时空条并保留图标与倒计时）；检测到与过热仪表盘等冲突时，支持在模组配置中切换至「冲突 HUD 上方 2px」或「屏幕右侧中部」。

## 蓝图系统优化与新增功能

- **3D 蓝图检视器方块替换功能 (`BlueprintBlockReplaceScreen`)**：
  - 将右侧材料清单标题调整为 **“方块清单(双击可替换方块)”**，并适当拓宽侧边栏避免标题截断。
  - 左键双击右侧方块清单中的任意方块条目即可打开专用替换方块选择界面：上方支持关键字搜索过滤，中部支持按原版及模组创造模式分类选项卡快速浏览（自动隐藏无方块的纯物品标签页，并在首标签页“全部方块”内置“空气（清除该方块）”、“水（水源）”与“熔岩（岩浆源）”特殊选项）。
  - 确认替换后将自动保留原方块的同名兼容状态属性（如朝向、上下半、含水状态等），自动清理类型不再匹配的旧方块实体 NBT，并实时刷新 3D 预览、材料清单、世界投影虚影以及蓝图桌当前预览数据/槽位结构蓝图物品；点击“取消”则不做任何修改。
  - 加入严格的多格方块保护校验：禁止将双格/多格方块（如门、床、模组多方块等）直接替换为普通单格方块，或不同多方块体系互替，并在触发时向玩家弹出清晰提示；替换流体时仅替换其源头格并自动清理对应的流动液体格为空气。
- **流体源头通用材料统计**：
  - 重构 `BlueprintBuildPlanner` 的蓝图材料统计与建造规划逻辑，通过通用流体状态判定（`FluidState#isSource()`），使所有原版及模组液体类方块（水、岩浆等）在材料清单、方块总数与大炮建造消耗中**仅计算源头格**，不再计入流动水/流动岩浆；同时保留 3D 预览界面中的流动液体完整视觉渲染与含水方块（Waterlogged）的正常计数。
- **蓝图大炮边界与解析安全性修复**：
  - 为 `BlueprintCannonBlockEntity`、`BlueprintBuildPlanner` 与 `LaunchedItem` 新增最大射程（`256` 格）、世界有效边界（`Level#isInValidBounds`）与区块已加载检查（`Level#isLoaded` / `hasChunkAt`），防止远端坐标触发服务端同步强制加载/生成区块，并杜绝超出世界建筑高度的目标坐标白白扣除材料与燃料却无法落地方块。
  - 修复 `BlueprintBuildPlanner#parseBlueprint`、`BlueprintDirectPlacer` 及预览网格中的 `width * length` 32 位整数溢出除零崩溃风险（`Width = Length = 65536` 时 `ArithmeticException`），并补齐 `y >= height` 截断保护防止篡改 `Blocks` 数组长度引发越界解析。
- **创造核心射速配置 GUI 与蓝图大炮发射速率自定义**：
  - 手持「创造核心」右键即可打开专用射速配置界面（`CreativeCoreScreen`），支持配置蓝图大炮检测到该创造核心时的发射速度（每 `1~1200` ticks 发射 `1~64` 次，默认为每 `5` ticks 发射 `1` 次），并在物品提示与 JEI 说明中实时展示当前配置。
  - `BlueprintCannonBlockEntity` 现已读取周围容器内创造核心的射速配置并按设定周期批量发射方块/实体，显著提升大中型蓝图的创造建造效率。

## 新增内容：装饰性钱币兑换合成配方

为装饰性钱币系列新增 **23 条有序合成与反向拆解配方**（13 条正向升面额合成 + 10 条反向降面额拆解），统一以摆放方向区分合成意图，彻底避免与筹码 1:1 互换配方及同面额双格合成产生冲突：

### 1. 排版区分规则
- **正向升面额（横排 / 横排优先）**：
  - 2 张同面额合成：横向并排 2 格（`XX`），2×2 随身合成格即可完成。
  - 5 张同面额合成：3×2 横排优先摆放（`XXX` / `XX `）。
  - 混合面额合成：按 `ABB` / `BBB`（1 张 5 元 + 5 张 1 元）或 `AAB`（2 张 20 元 + 1 张 10 元、2 张 200 元 + 1 张 100 元）横排摆放。
- **反向降面额（单格 / 竖排）**：
  - **无对应筹码的面额（5 元、10 元、20 元、200 元）**：单格放入 1 张即可拆解为对应低面额钱币。
  - **存在对应筹码的面额（100 元、1000 元、5000 元、10000 元、50000 元、100000 元）**：因单张钱币保留用于无序 1:1 兑换对应筹码，反向拆解统一改为 **竖排 2 张**（`X` / `X`），按 2 倍数量拆解输出（`4×` 或 `10×` 低面额钱币），与横排 `XX` 正向合成互不冲突。
- **混合面额配方**：`1×5元 + 5×1元 -> 10元`、`2×20元 + 1×10元 -> 50元`、`2×200元 + 1×100元 -> 500元` 仅提供正向合成，不生成反向拆解配方。

## 漏洞修复与稳定性优化

### 1. 专用服务端兼容与双端隔离
- **客户端 Mixin 双端隔离**：将纯客户端 `AnvilScreenMixin` 与 `GuiMixin` 从公共 `tuanzis_mod.mixins.json` 移至客户端专属 `tuanzis_mod.client.mixins.json`，避免专用服务端启动时因加载客户端类而崩溃。
- **公共类客户端依赖解耦**：将二段跳客户端发包与效果逻辑拆迁至 `ClientDoubleJumpHandler`，并为拾荒回廊装备槽位与容器新增无客户端依赖的 `ScavengerClientBridge` 桥接层，修复专用服务端运行期 `NoClassDefFoundError` 崩溃。

### 2. 物品防复制、防吞与数据持久化
- **铁砧整组物品防复制与彩虹海绵边界修复**：修复铁砧重命名整组可堆叠物品或彩虹海绵时左槽无条件写回导致无限复制的严重漏洞；加固彩虹海绵 `&q<n>` 渐变段数解析与 `[1, 128]` 区间限制，修复空白颜色段引发除零崩溃及 0 级可免费取出的问题。
- **方块破坏器活塞推动防复制**：结合 `BlockBreakerBlockEntity#preRemoveSideEffects`、`PistonMovingBlockEntityMixin`（落位附加 `UPDATE_SKIP_BLOCK_ENTITY_SIDEEFFECTS` 标志）与 `BlockBreakerPistonManager` 一次性原子消费，彻底解决普通/粘性活塞推拉、连推及 1-tick 短脉冲下原位掉落与目标格二次加载引起的物品复制。
- **机械比较器状态及时刷新**：清理方块破坏器、方块放置器与玩家模拟器 `affectNeighborsAfterRemoval` 中的无效死代码，改为直接调用 `Containers.updateNeighboursAfterDestroy`，修复破坏机器后红石比较器信号锁死不归零的问题。
- **黑匣子数据核心箱防复制与揭示状态持久化**：修复多格物品破坏时按占用格数成倍复制掉落的漏洞，并补全 `ScavengerLootContainerState` 中 `RevealedPlayers` 已揭示玩家记录的反序列化。
- **蓝图大炮燃料预判**：在 `BlueprintCannonBlockEntity#processEntityStep` 中先执行无副作用的 `hasFuel` 校验再扣除周围箱子材料，避免缺燃料暂停时白白吞掉实体建造材料。
- **旅者手札与工匠护符副手错位与防蒸发修复**：修复副手打开时客户端绑定主手并污染主手物品 NBT 的问题，锁定当前打开的手持槽位禁止丢弃/移走/交换，并在 `removed()` 补充服务端守卫。
- **抽卡券空卡池防吞券**：调整 `GachaItem` 扣减顺序，仅在抽取结果非空时消耗抽卡券。
- **塑世之笔大规模撤销堆叠合法化**：满背包撤销返还物品时按物品最大堆叠数分批拆分，杜绝生成超过 99 叠的非法 `ItemStack`。
- **灵笼贸易站同 tick 破坏村民保留**：改为依据实体是否已加入世界来判断释放逻辑，修复放入村民后立即破坏贸易站导致村民消失的问题。

### 3. 拾荒回廊系统优化与修复
- **战术整备与仓库交互安全加固**：修复背囊卸下时立即自动重穿的死锁；修复满格置换安全箱/背囊时未检查空位导致吞装备的问题；修复快捷栏/副手堆叠装备覆盖多余物品的问题；补充 `CONTAINER` 装备的活跃会话与已揭示校验及护甲回滚 `entryId` 保留；为 `BASE_STASH` 操作增加打开 `BaseStashMenu` 的服务端越权校验。
- **基地整备升级台独立缓存同步**：为基地仓库维护独立的客户端缓存并在打开升级台时主动同步，解决不先打开仓库直接点开升级台时材料计数显示为 0 的问题。
- **战术容器销毁自动关闭**：为 `ScavengerTacticalMenu#stillValid` 补充 `!container.isContainerRemoved()` 检查。

### 4. 战斗、状态效果、附魔与数值机制修复
- **肾上腺素到期并发异常修复**：将肾上腺素结束时的虚弱/挖掘疲劳施加与过载移除延后至 `LivingEntity#tick` 外部执行，彻底消除 `ConcurrentModificationException` 吞掉同 tick 后续效果的问题。
- **声波格挡与定桩锤伤害单次结算**：将 `SonicBoomBlockMixin` 改为独立 `@ModifyVariable` 乘算 `0.85F` 并通过 Mixin 优先级精确控制执行顺序，同时移除 `EarthPileHammerItem` 震荡波多余的手动 `DamageCalculator` 调用，消除伤害与受击钩子双重结算。
- **连锁苦痛友伤免疫透传**：为 `ChainPainDamageSource` 补全攻击者实体透传，使拾荒回廊同队玩家正确免疫溅射伤害。
- **星隙裁刃攻速 Buff 全局管理**：将攻速倒计时从 `inventoryTick` 迁至 `ServerTickEvents.END_SERVER_TICK` 按实体统一递减，修复多把武器加速过期及武器离身后攻速修饰符永久残留的问题。
- **假目标图腾护甲对齐**：移除重复写入基础护甲值的逻辑，避免假目标穿戴复制盔甲后护甲翻倍。
- **虚空锚跨维度安全回退**：按维度记录安全点，并在回退重生点时同步从 `globalPos.dimension()` 解析目标维度，修复跨维度触发虚空锚时维度与坐标不匹配的问题。
