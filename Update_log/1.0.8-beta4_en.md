# Tuanzi's Mod 1.0.8-beta4 Changelog

---

## Version Update

- Updated mod version to **1.0.8-beta4**.

## Bug Fixes & Stability Improvements

- **Fixed Dedicated Server Startup Crash on `PistonMovingBlockEntity` Mixin Transformation**:
  - Fixed a startup `InjectionError` (`Redirector tuanzis_mod$skipSideEffectsOnTickSetBlock ... Scanned 0 target(s). No refMap loaded.`) during `Blocks.<clinit>` on dedicated servers where other mods modify or overwrite `PistonMovingBlockEntity#tick`, causing Mixin's descriptorless selector to scan 0 targets.
  - Because vanilla `PistonMovingBlockEntity#tick` and `finalTick` already remove the moving piston block entity before placing the landed state—and `BlockBreakerBlockEntity#preRemoveSideEffects`, `setLevel`, `serverTick` fallback, `PistonBaseBlockMixin`, and `BlockBreakerPistonManager` already handle lossless migration and anti-duplication across regular/sticky piston pushes, chained pushes, and 1-tick short pulses—removed the redundant `PistonMovingBlockEntityMixin` registration (and archived the source file as `.bak`) to eliminate Mixin conflicts completely.
- **Fixed `NbtAccounterException` (2 MB Packet Limit Disconnect) When Opening Blueprint Table / Cannon With Large Color-Block Blueprints**:
  - `StructureBlueprintItem` now stores `Palette`, `Blocks`, `BlockEntities`, and `Entities` inside a transparent GZIP-compressed `CompressedPayload` byte array (shrinking a 13,824 Color-Block blueprint from ~6.3 MB to ~45 KB), keeping lightweight metadata (`Width`/`Height`/`Length`/`BlockCount`/`Ghost*`/`Offset*`/`Rotation`/`Mirrored`) uncompressed at the root so `container_set_content` stays far below vanilla's 2,097,152-byte limit.
  - `BlueprintTableBlockEntity` and `BlueprintCannonBlockEntity` automatically and losslessly compact legacy uncompressed blueprint items on chunk load, slot insertion, and menu open so existing saves self-heal without disconnecting.
  - Extended automatic lossless compaction to `ItemStack` deserialization (`ItemStack` `DataComponentPatch` constructor — covering `ItemEntity`, `ItemFrame`, `ItemDisplay`, player inventories, and vanilla chests/shulker boxes), `ItemEntity#setItem`, `ItemFrame#setItem`, and `StructureBlueprintItem#inventoryTick`, completely preventing `NbtAccounterException` disconnects during `clientbound/minecraft:set_entity_data` on existing worlds containing legacy uncompressed blueprints.
- **Fixed Villagers Inside the Soul Merchant Station Failing to Restock After `RestockTimer >= 8000`**:
  - Root cause: Nearby unemployed villagers could transfer an adjacent job site POI into a station villager's `POTENTIAL_JOB_SITE` memory via vanilla `YieldJobSite`, permanently locking the POI ticket (`freeTickets = 0`) because the `NoAI` villager never ticked its Brain—causing the station's `Occupancy.HAS_SPACE` check to reject its own job site; unclaimed adjacent job sites could also be stolen by free villagers within 48 blocks.
  - Fix: The Soul Merchant Station now **exclusively claims** one adjacent unoccupied matching job site as its dedicated `JOB_SITE` (preventing theft by nearby villagers and preventing multiple stations from sharing one job site), automatically self-heals legacy saves by promoting an adjacent `POTENTIAL_JOB_SITE` to `JOB_SITE`, cleanly releases the POI ticket on villager extraction, station break, or non-player removal (`preRemoveSideEffects`), and blocks `YieldJobSite` from targeting `StationVillager` or `NoAI` villagers via `YieldJobSiteMixin`.

## Feature Enhancements

- **True-Color Tinting & Per-Color Material List in Blueprint Table**:
  - Wired `BlockEntities` color NBT lookup into `BlueprintPreviewLevel` and `BlueprintPreviewMesh`, enabling **Color Blocks** (`tuanzis_mod:color_block`), **Color Stairs** (`tuanzis_mod:color_stairs`), and **Color Slabs** (`tuanzis_mod:color_slab`, including independent top/bottom colors) to render with their exact custom RGB colors in the Blueprint Table 3D Inspector, while optimizing mesh baking performance for large color-block blueprints.
  - Both the Blueprint Table material sidebar and the Blueprint Cannon's Material List Book now break down colored blocks by exact RGB hex color (e.g. `Color Block #AA71C5`) with dyed icons, color accent bars, and counts, and clicking a colored entry highlights only blocks of that exact color in the 3D preview.
- **Color-Aware Consumption & Paint Bucket Dyeing Fallback in Blueprint Cannon**:
  - When printing Color Blocks / Color Stairs / Color Slabs, the Blueprint Cannon now prioritizes consuming matching-color blocks from nearby containers (including nested Shulker Boxes / Golden Pockets).
  - If the exact color is unavailable, the cannon checks for a **Paint Bucket** (`tuanzis_mod:paint_bucket`) with remaining durability and any other-colored block of the same type, consuming **1 Paint Bucket durability + 1 other-colored block** to dye and place the target color (turning the Paint Bucket into an empty `minecraft:bucket` when depleted, matching crafting behavior); otherwise it pauses for missing materials.
- **Improved Entity List Display in Structure Blueprint Tooltips**:
  - When a Structure Blueprint contains more than 4 entities, its item tooltip now shows only the first **4** entity rows by default along with a `Hold Shift to show all` summary line; holding `Shift` expands the full entity list.
  - Added cached entity summary decoding for compressed blueprints (`CompressedPayload`) when `EntityCount > 0`, ensuring full entity lists are available on newly recorded and imported blueprints without decompressing every hover frame.
- **Creative Core Exempts Compressed Build Slurry Consumption**:
  - When a Blueprint Cannon detects a **Creative Core** (`tuanzis_mod:creative_core`) in nearby containers, `hasFuel` and `consumeFuel` now bypass fuel checks and deductions, no longer consuming **Compressed Build Slurry** or stored fuel durability (allowing fuel-free construction and destruction even in Survival mode).
- **Improved White & Light Bead Recognition in the Bead-to-Blueprint Converter Tool**:
  - Added dark color-code text detection inside white/near-white cells (using HSV value channel `max(R,G,B)` and vertical bright-margin/dark-center dip contrast) to reliably distinguish **labeled white/light bead cells** from **blank white background, red 10×10 grid lines, and adjacent dark-outline bleed**; white beads are now preserved with their true color (`tuanzis_mod:color_block`) instead of being converted to air, even along outer edges.
  - Isolated white/near-white foreground clustering during color purification so small white highlights or off-white shades are not swallowed into nearby light skin/pastel tones under default ΔE merging.
